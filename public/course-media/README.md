# Course media

Drop recordings in here and they appear on the site automatically — no code change, no redeploy setting to flip. Until a file exists, the lesson shows the script (for video) or a short "coming soon" note (for audio), so nothing is broken by a file that is not ready yet.

File names must match exactly, lower case, including the extension.

### Silence timer

Script for both lines: `audio/silence-timers.md`. The platform inserts the silence between the opening and the closing, so one closing clip serves every length.

| File | Spoken |
|---|---|
| `timer-opening-5.mp3` | the opening line, naming 5 minutes |
| `timer-opening-10.mp3` | the opening line, naming 10 minutes |
| `timer-opening-15.mp3` | the opening line, naming 15 minutes |
| `timer-opening-20.mp3` | the opening line, naming 20 minutes |
| `timer-opening-30.mp3` | the opening line, naming 30 minutes |
| `timer-closing.mp3` | the closing line |

Lengths offered are 5, 10, 20, 30 minutes, plus any different length a session suggests (15 at present).

If an opening clip is missing the timer still runs, silently, and ends with a soft chime made in the browser. Recording the openings is optional; recording the closing is the one that most changes how the silence ends.
