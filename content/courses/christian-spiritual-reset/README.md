# Course content: The Christian Spiritual Reset

- course.json — course metadata: 5 modules, 28 lessons in order, with file paths.
- lessons/NN-slug.md — lesson body in Markdown (GFM tables used). Front matter: title, module, order, source, type (teaching | session | reference).
- quizzes/NN.json — per lesson: `questions` (multiple choice: q, options[4], answer = index of the correct option, explanation shown after answering), `pass_mark`, and `reflection` (free-text journal prompts). Teaching chapters have both; retreat sessions have reflection only (questions is empty); lesson 23 (reference) has neither.
