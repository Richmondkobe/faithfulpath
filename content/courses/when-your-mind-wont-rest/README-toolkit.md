5. **Cross-reference table rebuilt** with wrapped paragraph cells and proper row heights; no collisions.
6. **Worksheet 24's missing ending restored** — "…what actually belongs under 'seek help' or 'safety.'" The Markdown source was truncated; it is fixed in `resources/24-…`, so re-copy that file into `m0/resources/`.

8. **Contents no longer splits a section** across pages; each section block is kept together.
