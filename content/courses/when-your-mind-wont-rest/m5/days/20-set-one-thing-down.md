# Day 20: Set one thing down

**Action** · Week Three: Release

## Scripture

“Whatever is true… think about these things.”

## Focus

Lesson 15. Not everything true deserves dwelling. The six questions of the Philippians 4:8 Pastoral Attention Test are an applied framework, not translations of Paul’s eight descriptions.

## Practice

No worksheet. Choose one thing you have been dwelling on that the attention test would place under “know and set down” or “decline”: a news thread, a comparison, an old grievance, a feed. Take one practical step today to stop feeding it. Then do the “today” item from Day 19, if there was one.

## Prompt

What did I do instead with the attention I set down?
